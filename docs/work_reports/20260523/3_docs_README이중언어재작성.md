- 작업일: 2026-05-23
- 작업 유형: docs
- 담당: Claude

## 목표

GitHub에서 README.md를 열었을 때 한국어 설명이 먼저 보이고, 영어 설명이 바로 이어서 보이도록 단일 파일 이중 언어 구조로 재작성.

## 변경 파일

| 파일 | 변경 유형 | 내용 |
|------|----------|------|
| `README.md` | 수정 | 한국어(상단) + 영어(하단) 이중 언어 구조로 전면 재작성 |

## 변경 내용

### 구조

```
README.md
├── [한국어 섹션]
│   ├── 제목 + 한 줄 설명
│   ├── 목차
│   ├── 요구 사항
│   ├── 빠른 시작
│   ├── 처음 실행
│   ├── DB 업데이트 (신규 벤더 API 방식 반영)
│   ├── 오프라인 / USB 모드
│   ├── 빌드
│   ├── 드라이버 수동 추가
│   ├── 디렉토리 구조
│   └── 참고 사항
├── --- (구분선)
└── [English Section]
    └── (동일 구조, 영문)
```

### 주요 내용 변경

- **DB 업데이트 섹션 신규 추가**: 이번 작업에서 구현한 벤더 API 직접 조회 방식 설명 포함
  - 네트워크는 DB 업데이트 / 파일 다운로드 시에만 사용됨을 명시
  - NVIDIA(GFE API), AMD(Radeon JSON), Intel/Realtek(정적) 구분 설명
- **CDN/remote_manifest 설정 섹션 제거**: 제거된 기능이므로 삭제
- **디렉토리 구조에 `vendor_api.py` 추가**: 신규 파일 반영
