# 다운로드 403 오류 수정 (Referer 헤더 추가)

- 날짜: 2026-05-22
- 작업 유형: fix
- 작업자: Claude

## 문제

DB 업데이트 시 Intel 드라이버 9건 전부 403 Forbidden 오류 발생:

```
[ERROR] Download failed (...SetupChipset.exe): 403 Client Error: Forbidden for url: .../setupchipset.exe
[ERROR] Download failed (...WiFi-23.80.0-Driver64-Win10-Win11.exe): 403 ...wifi-23.80.0-...exe
Download complete: 0/9 succeeded
```

## 원인 분석

`downloadmirror.intel.com`은 직접 다운로드 요청에 대해 `Referer` 헤더를 검증한다.
`Referer` 없이 요청하면 서버가 403을 반환하거나, 소문자 경로로 리다이렉트 후 다시 403을 반환한다.

기존 코드의 문제:

```python
# 수정 전 — 불완전한 User-Agent, Referer 없음
headers = {"User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64)"}
```

| 문제 | 내용 |
|---|---|
| User-Agent 불완전 | 브라우저 엔진 정보 누락 → 봇 감지 가능성 |
| Referer 없음 | Intel 서버 정책상 403 반환 |

## 수정 내용

**파일:** `core/downloader.py`

### 1. 도메인별 Referer 매핑 테이블 추가

```python
_REFERER_MAP: dict[str, str] = {
    "downloadmirror.intel.com": "https://www.intel.com/",
    "download.intel.com":       "https://www.intel.com/",
    "us.download.nvidia.com":   "https://www.nvidia.com/",
    "international.download.nvidia.com": "https://www.nvidia.com/",
    "drivers.amd.com":          "https://www.amd.com/",
    "www.realtek.com":          "https://www.realtek.com/",
}
```

### 2. 완전한 User-Agent 상수 정의

```python
_USER_AGENT = (
    "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
    "AppleWebKit/537.36 (KHTML, like Gecko) "
    "Chrome/124.0.0.0 Safari/537.36"
)
```

### 3. `_build_request_headers(url)` 헬퍼 함수 추가

```python
def _build_request_headers(url: str) -> dict[str, str]:
    domain = urlparse(url).netloc.lower()
    referer = _REFERER_MAP.get(domain, "")
    headers = {
        "User-Agent": _USER_AGENT,
        "Accept": "*/*",
        "Accept-Language": "en-US,en;q=0.9",
        "Connection": "keep-alive",
    }
    if referer:
        headers["Referer"] = referer
    return headers
```

### 4. `_download_file()`에 적용

```python
# 수정 전
headers = {"User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64)"}

# 수정 후
headers = _build_request_headers(url)
```

## 결과

- Intel: `Referer: https://www.intel.com/` 자동 추가로 403 해소 예상
- NVIDIA, AMD, Realtek: 벤더별 Referer 사전 등록으로 향후 동일 문제 예방
- 신규 도메인은 Referer 없이 요청 (기존 동작 유지)
